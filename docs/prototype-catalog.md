# Prototype Catalog

This document is a working classification of the experiments in this repository. It is based on a limited review; entries should be revisited before files are renamed, consolidated, or removed.

## Reviewed Experiments

- `dashboard.html` and `dashboard.js`: cloud-connectivity dashboard prototype with in-memory records and file-import interaction.
- `DC`: AWS Direct Connect data-collection experiment.
- `DM-vis-1`: browser-based network configuration impact visualization.
- `DM-Vis-2`: Python graph/configuration analysis experiment.
- `Gem_Visual_1`, `Gem_Visual_2`, `Gem_Visual_3`: related configuration parsing and network graph experiments.
- `Gro-Vis-1`, `Gro_vis_2`, `Gro-Vis_3`: Cisco configuration parsing and visualization variants.
- `path`: network path-analysis command-line experiment.
- `three-csp`: cloud connectivity information collection prototype.

## Consolidation Notes

- The three Gem_Visual variants and three Gro-Vis variants are candidates for code comparison and consolidation, but they have not been proven identical.
- Do not remove historical variants until their functionality and differences are documented.
- Use synthetic data when testing or publishing screenshots.
- This catalog is incomplete; other repository files still need a detailed review.
